Configuración de Cloudflare — Despliegue y CDN Global

Publicación instantánea de sitios demo y propuestas con HTTPS automático en Cloudflare Workers

Cloudflare Workers API
CDN Global Edge
Objetivo: Vincular tu cuenta de Cloudflare para que el Agente IA pueda compilar y desplegar los sitios rediseñados y propuestas interactivas directamente a internet con un solo comando (o mediante el plugin deploy-cloudflare). El sitio queda publicado bajo tu dominio personalizado (ejemplo: https://demos.aisalesradar.com/oxy-dental-los-angeles/) con certificado SSL de alta seguridad y tiempos de carga inferiores a 200ms en todo EE.UU.
1

Acceder al Panel de Cloudflare

Inicia sesión en Cloudflare con tu cuenta de agencia:
https://dash.cloudflare.com
2

Localizar tu Account ID (ID de Cuenta)

En el panel de Cloudflare:
  • Haz clic en tu dominio (ej. aisalesradar.com) o en la sección Workers & Pages en el menú lateral.
  • En la columna derecha de la pantalla (sección API), localiza Account ID.
  • Es un hash hexadecimal de 32 caracteres (ejemplo: 534190a0d0708744cbb88312512e92d0).
  • Haz clic en Click to copy para copiarlo.
3

Crear el API Token con Permisos de Workers

Para que el sistema tenga permiso para subir los archivos de las demos sin exponer tu contraseña:
  • Ve directamente a la sección de API Tokens de tu perfil:
https://dash.cloudflare.com/profile/api-tokens
  • Haz clic en el botón azul Create Token.
  • Puedes seleccionar la plantilla preconfigurada Edit Cloudflare Workers (clic en Use template), o crear un Custom Token con estos permisos mínimos:
    • Account ➔ Workers Scripts ➔ Edit
    • Account ➔ Account Settings ➔ Read
    • Zone ➔ Workers Routes ➔ Edit
    • Zone ➔ DNS ➔ Edit (necesario para asignar automáticamente el dominio personalizado)
  • En Account Resources, selecciona tu cuenta (All accounts o tu cuenta específica).
  • Haz clic en Continue to summary y luego en Create Token.
  • Copia el Token generado inmediatamente (Cloudflare solo te lo mostrará una única vez).
Referencia oficial: Asistente de creación de API Tokens en Cloudflare Dashboard.
4

Ingresar la configuración en el Panel del CRM

  • Abre el panel en http://localhost:8765 y ve a la pestaña Configuración.
  • En la columna lateral derecha, despliega: ☁️ Conexión Cloudflare — Despliegue y CDN Global.
  • Ingresa los siguientes valores:
    • Cloudflare Account ID: 534190a0d0708744cbb88312512e92d0
    • Nombre del Proyecto: prospector-sites (o el nombre que prefieras).
    • Dominio Personalizado: aisalesradar.com (tu dominio registrado en Cloudflare).
    • Subdominio de Demos: demos (publicará en demos.aisalesradar.com).
    • Cloudflare API Token: Pega el token generado en el Paso 3.
  • Haz clic en Guardar Cloudflare. La etiqueta cambiará a ✓ Token activo.
